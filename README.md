Text frequency analyzer

Requirements: 
For the program to run correctly, it’s necessary for the files that will be used, to be in the same folder as the code.

Features:
- Case-insensitive character and word counting.
- Ignores punctuation and non-alphanumeric characters.
- Outputs results to console and exports to `characters.txt` and `words.txt`.

Description: 
The program calculates the frequency of characters and the frequency of words contained in the file chosen by the user. As a result, it shows the 10 most frequent characters and words. All the data is saved all in two files (characters.txt for the characters and words.txt for the words).


How to run it:
1. Start the program. You will be asked to type the name of a file. 
2. Type the name of the text file where you want the letter and word frequencies counted. *(There’s already a sample file in the folder called `input.txt` that can be used by changing its content).*
3. After the counting is done, the 10 most frequent characters and words will be displayed. Any punctuation marks will be removed if they exist. 
4. If you want to see all the data, you can open the files `characters.txt` and `words.txt`, which will be generated in the folder with the code.
